## Acerca del Proyecto Base
Este repositorio contiene un programa interactivo en Python diseñado como base para una práctica avanzada de Git. El proyecto es un Sistema de Conversiones operado por consola que servirá para que el equipo trabaje en ramas paralelas, resuelva conflictos y practique el flujo de trabajo colaborativo.

Cómo ejecutar el proyecto
Asegúrate de tener Python 3 instalado y ejecuta el siguiente comando en la terminal desde la raíz del proyecto:

```python3 main.py```
